# ESP32C3mini_Ecue —— ECUE 台球灯效固件（M4）

ESP32-C3 mini + 32 颗 WS2812 灯条 + 压电撞击传感器 + 双按键。
PlatformIO 工程（espressif32@6.5.0 / Arduino core 2.0.14 / USB CDC），打开即编译：`pio run`。

当前版本 **M4**（2026-10-03）：在 M3「11 档预设灯效 + 32 灯」基础上，新增
**亮度四档调节（btn1 长按 2s）** 与 **双键同按现场重标定**，键位终局闭环，
交互口径见《亮度与重标定-交互口径稿-v2.1》。

---

## 一、功能总览

| 模块 | 说明 |
|---|---|
| 预设灯效模式 | 11 档循环（0-4 基线 + 5-10 开球爆散/母球游走/黑八环转/彩球进袋/星尘/火焰） |
| 传感器模式 | 压电撞击实时响应，四态风格（M1 脉冲 / S1 白闪 / S2 长度条 / S3 波纹） |
| 亮度调节（M4） | 四档 50/100/150/200，btn1 长按 2s 进刻度尺模式，NVS 断电记忆 |
| 现场重标定（M4） | 双键同按 500ms：慢呼吸 → 进度条（32 次均值）→ 白双闪 |
| 待机 | btn2 长按 2s，300ms 从当前档线性渐灭；任意短按/长按唤醒 |
| NVS 断电记忆 | 预设档 / 风格档 / 亮度档（四字段包，兼容旧三字段包，免迁移） |

## 二、硬件与接线

| 部件 | GPIO | 说明 |
|---|---|---|
| WS2812 灯条 | GPIO7 | 32 颗，NEO_GRB + KHZ800 |
| btn1（效果/亮度） | IO0 | 内部上拉，按下=低（另一端接 GND） |
| btn2（互切/待机） | IO10 | 同上 |
| 压电传感器 AO | GPIO4 | ADC1_CH4，11dB 衰减（勿把 IO0 加入 ADC 扫描） |

> 按键若实物另一端接 3.3V：把 `piezo_config.h` 的 `BUTTON_ACTIVE_LOW` 改为 `false`
> （自动改用下拉），语义不变。

**供电红线**：32 灯全白 @255 ≈ 1.9A。USB 直供调试期亮度请停留在 100（≈0.75A）；
**>100 的档位（150/200）仅在外接 5V≥2A 或电池下安全**（200 档全白 ≈1.5A）。
固件不做供电感知硬钳（无 USB 检测脚）。

## 三、按键功能表（键位终局）

| 手势 | 常规态 | 亮度模式内 |
|---|---|---|
| btn1 短按 | 效果档循环（零延迟） | 升 1 档 |
| btn2 短按 | 预设/传感器互切（零延迟） | 降 1 档 |
| btn1 长按 ≥2s | **进亮度模式** | 按住=连发上行（延续） |
| btn1+btn2 同按 ≥500ms | **现场重标定** | 屏蔽 |
| btn2 长按 | 待机渐灭 | 屏蔽 |
| btn1/btn2 双击 | 空闲（反向循环已拍"不加"） | 屏蔽 |
| 待机中任意按键 | 短按/长按=唤醒（不进亮度、不做组合判定） | — |

组合键细则：第二键在首键按下后 ≤150ms 内落下=同按成立，期间两键短按/长按全部
屏蔽；保持满 500ms 触发重标定；中途松手=作废并吞掉本次短按（不补偿触发）。

## 四、亮度调节（M4）

- **进入**：btn1 按住 2s（零副作用，短按为释放沿判定，按住过程不切效果）。
- **刻度尺**：灯条变刻度——8/16/24/32 灯 = 50/100/150/200 四档，白色，所见即所得。
- **调档**：按住连发（每 500ms 升一档）；松手后短按 btn1 升 / btn2 降（按下沿生效）。
- **边界**：到 200 顶格停住不回绕（再按 btn1 当前刻度 200ms 呼吸提示）；底格对称。
- **保存**：2s 无操作自动退出，NVS 写入一次，整条白快闪确认，返回原模式
  （预设/传感器状态零扰动，传感器模式内撞击渲染暂停、退出即恢复）。
- **记忆**：出厂默认 100（恰为第 2 档）；断电/重启/互切/唤醒一律恢复当前设定档；
  待机渐灭从当前档起（300ms 线性），唤醒恢复同值。

## 五、现场重标定（M4）

双键同按保持 500ms 触发（常规态任意模式下可用）：

1. **慢呼吸** 600ms（台呢绿，提示已受理）；
2. **进度条** ≈1.3s：32 次静息采样按 32 灯节奏展开（40ms/次，比瞬时重采更抗噪；
   自动避开撞击采样窗口防污染）；
3. **完成**：满条保持片刻 → 白双闪 → 回常规显示。期间所有按键忽略。

重采口径与 `reseedRest()` 相同（32 次均值）；无可判失败条件，不设失败分支
（错误码机制预留）。

## 六、使用流程（标定 → 运行）

1. **压电标定**：给 `platformio.ini` 的 build_flags 临时加 `-DAPP_MODE_PIEZO_TEST`
   重编译（默认编译的是运行时固件，见 `src/main.cpp` 头注），烧录后敲击/捏传感器
   记录串口 CSV 的 `swing` 典型值。
2. **填阈值**：`include/piezo_config.h` —— `PIEZO_TRIGGER`（触发，默认 150）、
   `IMPACT_LEVEL1`（600 → 黄）、`IMPACT_LEVEL2`（1500 → 红）。
3. **切运行固件**：移除该宏重新编译（默认即运行时），开机恒进预设灯效模式。
4. 标定完成后可把 `src/cue_controller.cpp` 的 `DEBUG_IMPACT` 改 `false` 关打印。
5. **硬件整改警示**：C12 仍为 10pF 时输出贴轨、任何触碰 swing 顶满数千码属预期；
   换 C12=1nF 后幅度缩小约 100 倍，必须重新标定（硬件整改清单见
   《ESP32C3_Piezo_改进方案》）。

## 七、编译与烧录

```bash
pio run                # 编译（esp32-c3-devkitm-1）
pio run -t upload      # 烧录（USB CDC）
pio run -t upload -e <env>   # 多环境时显式指定
```

- 串口 **115200**，开机横幅：`[ecue] runtime firmware ready (M4)`，
  随后打印恢复的 `effect/style/bright` 档位。
- 免编译烧录：用交付包内 `flash_bin/` 三件套（bootloader @0x0、partitions @0x8000、
  firmware @0x10000，ESP32-C3）。

## 八、调参速查（include/piezo_config.h，单一来源）

| 参数 | 默认 | 含义 |
|---|---|---|
| `LED_COUNT` | 32 | 灯珠数（M3 起；0-29 与旧版逐位等价，30/31=母球位） |
| `LED_BRIGHTNESS_MAX` | 100 | 供电警示锚点常量（运行档位已改 NVS 可调，见 `BRIGHT_LEVELS`） |
| `BRIGHT_LEVELS` | {50,100,150,200} | 亮度四档（255 标度） |
| `BRIGHT_DEFAULT_INDEX` | 1 | 出厂默认档（=100） |
| `BUTTON_DEBOUNCE_MS` / `BUTTON_LONGPRESS_MS` | 40 / 2000 | 消抖 / 长按阈值（亮度入口与待机同值） |
| `BUTTON_COMBO_WINDOW_MS` / `BUTTON_COMBO_HOLD_MS` | 150 / 500 | 同按成立窗 / 重标定保持 |
| `BRIGHT_REPEAT_MS` / `BRIGHT_IDLE_EXIT_MS` | 500 / 2000 | 连发节拍 / 模式内无操作退出 |
| `RESEED_BREATH_MS` / `RESEED_STEP_MS` | 600 / 40 | 重标定呼吸时长 / 采样节奏 |
| `PIEZO_TRIGGER` / `IMPACT_LEVEL1/2` | 150 / 600 / 1500 | 触发与力度分档阈值（码） |
| `PIEZO_WINDOW_US` / `PIEZO_REFRACT_MS` | 30000 / 200 | 采样窗 / 静默期 |
| `STRIKE_CONTINUOUS` | 0 | 力度连续映射开关（标定数据到位后置 1） |
| `NVS_ENABLED` / `NVS_NS` / `NVS_KEY` | true / "ecue" / "state" | 断电记忆开关与命名 |

## 九、NVS 记忆口径

- 单 key（`ecue/state`）**四字段打包**：effect / style / mode（保留恒 0）/ bright。
- **兼容旧包**：读到 M2/M3 的 3 字节旧包时效果/花色照常恢复，亮度落默认档 100，
  无需迁移；越界值一律回退默认档。
- 写点：档位变更处（效果/风格）+ 亮度模式退出瞬间（一次会话至多一次写），
  全部位于采样窗口门外（P1-2 冻结纪律）。

## 十一、已知边界

- 反向循环不加（2026-10-03 拍板"3不加"），btn1/btn2 双击均空闲。
- 窗口期（撞击 30ms 采样窗）内禁止一切 `show()`：按键与渲染延后一个窗口（P1-2）。
- 亮度模式内为事件驱动画面，静置不刷帧（省电且无闪烁）。
- 固件不含 USB 检测，高档位用电安全依赖使用口径（见第二节供电红线）。
